# SetupFinder 🚀

Sistema backend que cadastra peças de PC e sugere setups completos com melhor custo-benefício, usando lógica de IA/banco de dados.

## ✨ Funcionalidades (em desenvolvimento)
- Cadastro de peças (CPU, GPU, RAM, etc.)
- Conexão com banco H2 para armazenamento
- Sugestão de combinações compatíveis (próximos passos: integrar IA real ou regras de compatibilidade)

## 🛠️ Tecnologias
- Java 17/21
- Spring Boot 3
- Spring Data JPA
- Banco de dados: H2 (embutido por enquanto)
- Maven
